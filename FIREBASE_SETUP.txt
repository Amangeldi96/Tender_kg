TENDERFLOW — Firebase настройка

1. Authentication -> Sign-in method -> Email/Password күйгүзүңүз.

2. Authentication -> Settings -> Authorized domains:
   Сайтыңыздын доменин кошуңуз.

3. Authentication -> Templates -> Password reset:
   Action URL / Customize action URL бөлүгүндө TenderFlow сайтыңыздын URL'ин көрсөтүңүз.
   Мисалы:
   https://YOUR-DOMAIN.com/

Firebase катка mode=resetPassword жана oobCode параметрлерин кошот.
Бул проект ошол параметрлерди окуп, өзүнүн 8 цифралык PIN reset барагын ачат.

4. Firestore Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /companies/{companyId} {
      allow read: if true;
      allow create, update, delete: if request.auth != null
                                   && request.auth.uid == companyId;
    }
    match /tenders/{tenderId} {
      allow read, write: if request.auth != null;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

5. npm install
6. npm run dev

PIN: так 8 цифра. Тамга жана 9-цифра кабыл алынбайт.
